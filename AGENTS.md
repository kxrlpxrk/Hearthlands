# Hearthlands development rules

- Document data is the single source of truth, never canvas pixels.
- Keep procedural generation deterministic using seeded randomness.
- Use typed, modular functions and reusable components.
- Design mouse and touch interactions together.
- Don't introduce unnecessary dependencies, paid APIs or backends.
- Don't add nonfunctional controls pretending to work.
- Preserve existing features in later tasks.
- Run available checks and report failures honestly.
